# Agendaê — MVP v1

Primeira versão funcional do aplicativo de agendamento.

## O que já funciona

- Tela inicial
- Área profissional
- Cadastro simples do nome, serviço, preço e duração
- Seleção dos dias de atendimento
- Horários disponíveis
- Bloqueio/desbloqueio de horários
- Área do cliente
- Seleção de dia e horário
- Nome e WhatsApp
- Confirmação de agendamento
- Agendamento aparece na agenda da profissional
- Cancelamento de agendamento pela área profissional
- Persistência local no navegador via localStorage
- Manifesto PWA para instalação como atalho/app no celular

## Importante

Esta é uma versão de protótipo/MVP. Os dados ainda ficam somente no aparelho/navegador onde o app está aberto.

Para virar um produto real multiusuário, a próxima etapa é adicionar:
1. autenticação;
2. banco de dados online;
3. contas separadas de profissionais e clientes;
4. links públicos individuais para cada profissional;
5. sincronização dos horários em tempo real;
6. lembretes/WhatsApp;
7. painel administrativo;
8. publicação como aplicativo nativo.

## Como testar

Abra `index.html` em um navegador ou hospede os arquivos em um serviço de hospedagem estática.

No celular, o navegador poderá oferecer a opção de adicionar o site à tela inicial quando hospedado em HTTPS.
